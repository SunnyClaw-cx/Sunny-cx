### 早停法的量纲陷阱（已修复，写代码必看）

西瓜书说"验证误差升高则停"，但工程实现有个坑：

```python
# ❌ 错误：比较步数差。val_interval=500 时 patience=5 永远只等于 1 次验证
if step - best_step >= patience:
    stop()

# ✅ 正确：按「验证次数」计数
if val_loss < best_val - min_delta:
    bad_count = 0
else:
    bad_count += 1
    if bad_count >= patience:
        stop()
```

> **教训**：早停的 patience 语义是"**连续多少次验证没变好**"，不是"多少步"。
> 用步数差会让 patience 随 val_interval 缩放，完全失控。

## 三、模型架构（524.13M）

```
hidden_size          : 1152
num_hidden_layers    : 32
num_attention_heads  : 12        head_dim = 96
num_key_value_heads  : 4         GQA，4 个 q 头共享 1 组 kv
intermediate_size    : 3648      = ceil(1152·π/64)·64   ← 注意是 3648，不是 5760
vocab_size           : 6400      自训中医 BPE
max_position         : 32768     rope_theta = 1e6
norm                 : Pre-Norm + RMSNorm
activation           : SwiGLU
tie_word_embeddings  : True      输出层复用词嵌入
```

> ⚠ 常见错误：SwiGLU 的 intermediate 若按 4d = 4608 或按 Llama 的 8/3·d 再调，会算错。
> 本项目用的是 `ceil(d·π/64)·64 = ceil(1152×3.14159/64)×64 = ceil(56.55)×64 = 57×64 = 3648`。

## 四、参数量公式（真机校准，误差 0）

```
N = V·d + L·(2d² + 2d·kv·hd + 3d·inter) + d
        │         │         │            │
        │         │         │            └─ SwiGLU 的 gate / up / down 三个矩阵
        │         │         └─ k_proj / v_proj（GQA 下 kv 头少，省参数）
        │         └─ q_proj / o_proj 各 d²
        └─ 词嵌入（与 lm_head 绑定，只计一次）
```

**实测 524,133,504；公式 524,133,504；差异 0。**

### 参数构成拆解（实测占比）

| 组件 | 参数量 | 占比 |
|---|---|---|
| embed_tokens（与 lm_head 绑定） | 4,915,200 | 7.69% |
| attn q/k/v/o | 14,157,312 | 22.15% |
| MLP SwiGLU gate/up/down | 44,826,624 | 70.14% |
| RMSNorm | 13,056 | 0.02% |

> **读数要点**：MLP 占了 70% 的参数。这就是为什么 SwiGLU 的 intermediate 尺寸
> 对总参数量影响最大——改它比改层数更"划算"。

## 六、训练配置（正式口径）

| 项 | 值 | 理由 |
|---|---|---|
| batch_size | 2 | 6GB 卡上限（batch=4 OOM） |
| max_seq_len | 512 | — |
| accumulation_steps | 8 | 等效 batch 16 |
| learning_rate | 3e-4 | 线性 warmup 200 步 + cosine 退火到 0.1×base |
| epochs | 2 | 上限 3；过拟合首要风险 |
| gradient_checkpointing | **必开** | 保 6GB 不 OOM |
| weight_decay | 0.1 | 排除 bias / norm（西瓜书 5.3） |
| grad_clip | 1.0 | fp32 下累加范数 |
| dtype | float16 | sm_61 不支持 bf16 |
| val_interval | 200 | 真实验证 + 更新 best |
| save_interval | 100 | 意外中断最多损失 100 步 |

启动：
```bash
python -u scripts/train.py --stage pretrain --config 0.5b \
  --batch_size 2 --max_seq_len 512 --accumulation_steps 8 \
  --learning_rate 3e-4 --epochs 2 --gradient_checkpointing \
  --val_interval 200 --val_samples 64 --save_interval 100 \
  --save_weight sunnycx_0.5b_pretrain --from_resume
```
